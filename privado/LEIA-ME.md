# Pasta privada (ignorada pelo Git)

Tudo o que estiver aqui fica só neste computador. Apenas este arquivo vai para o repositório público.

Esta pasta guarda os dados reais do projeto:

- Planilhas reais de controle e programação de férias.
- Relatório de férias da contabilidade.
- Transcrições de conversas e respostas do gestor.
- O banco de dados real (`.sqlite`) e as cópias de segurança dele.
- Configurações com nomes reais de clientes, centros de custo e times.

Nada desta pasta deve ser copiado para arquivos versionados. Para exemplos e testes, use `data/exemplo/` e `config/regras_iniciais.exemplo.json`.
